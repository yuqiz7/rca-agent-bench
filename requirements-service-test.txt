# What the service's own test files need, on top of a plain checkout.
#
# THREE ENVIRONMENTS, ON PURPOSE:
#
#   CI today            pytest + PyYAML only (.github/workflows/ci.yml). Gates 1-3
#                       must run on a checkout with no network, so everything the
#                       service adds to tests/ skips cleanly there.
#   CI gate 4           requirements-service-ci.txt, included below: gate 4 is the
#                       OFFLINE half (schema units + the OpenAPI snapshot) and
#                       nothing more -- no database driver, no HTTP client.
#   local               this whole file, plus RCA_TEST_DB_URL pointing at the
#                       Postgres from docker-compose.service.yml, which turns on
#                       the repository and 422 tests. Design §6: DB tests and smoke
#                       are local gates, never CI ones.
#
# anthropic is deliberately ABSENT. service/app/harness.py imports the arm modules
# inside functions, so the app builds without the model client -- and a test venv
# that cannot import it is what keeps that true.
-r requirements-service-ci.txt
